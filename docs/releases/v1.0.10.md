## ⚠️ Upgrading a .deb / .rpm from v1.0.9 or earlier

Those versions deleted every user's LazyChad config and plugins when the
package was upgraded. This release moves your data aside while the old
package's removal script runs and puts it back afterwards (tested in CI
against the published v1.0.9 packages), but **back up `~/.config/LazyChad`
before upgrading** to be safe. After this release, upgrades and plain
removals never touch your data; only `apt purge` and `lazychad-uninstall` do.

## Highlights

- **One-line install** for Arch, Debian/Ubuntu/Kali and Fedora (RHEL clones
  with EPEL):
  `curl -fsSL https://raw.githubusercontent.com/MistanKh/LazyChad/main/install.sh | bash`
- **Stable Neovim by default.** `lazychad-nvim` installs the latest stable
  release (0.12+); `--nightly` is opt-in. Downloads are verified against
  GitHub's published SHA-256 digests.
- **Ready on first launch.** `lazychad-deps` now installs plugins, base Mason
  tools and treesitter parsers, so `lchad` opens straight into a working
  editor. No more `:MasonInstallAll`.
- **`lchad --doctor`** checks Neovim, tools, providers, font, config and
  plugins. Also new: `lchad --setup` and `lchad --bootstrap`.
- **Leaner setup.** The Neovide GUI and Rust are opt-in (`lazychad-deps --gui`);
  pynvim comes from your distro; the Node provider and tree-sitter CLI go into
  a private folder instead of `sudo npm -g`; JetBrainsMono Nerd Font is
  installed on Debian/Fedora.
- **Python and Node providers work** (NvChad was disabling them).

## Fixes

- Pickers: closing one with `:q` no longer freezes the rest; picking `ruff`
  formats instead of running lint fixes; "None" really disables format on
  save; per-server LSP handlers (vue_ls, pyright, ts_ls...) are kept; switching
  LSPs stops the old one; saved choices survive projects with local
  `node_modules` tools.
- `lazychad-uninstall` stops before touching anything if the package removal
  fails, purges on Debian, honours XDG dirs and removes the whole Neovim
  install.
- `lazychad-deps` installs system packages before Neovim, copes with NodeSource
  / LTS Node and other equivalent packages, and does a best-effort run on
  distros it has no package list for.
- The AUR package now builds from the tagged release with a pinned checksum.
